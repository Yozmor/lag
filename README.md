<h1 align="center">Лаг</h1>

<p align="center">Диагностика интернет-соединения и блокировок: что заблокировано и как именно — по IP, по DNS или по SNI, работает ли VPN, где на маршруте теряются пакеты.</p>

Назван в честь лага — морского прибора, которым измеряли скорость судна.

Lag — **диагностический сенсор**: он ничего не обходит и не туннелирует, он измеряет и показывает, что делает с твоим трафиком сеть провайдера (в т.ч. ТСПУ). Результаты сохраняются в текстовые отчёты и в машиночитаемый JSON.

## Две версии

| | [`windows/`](windows/) | [`linux/`](linux/) |
|---|---|---|
| Интерфейс | окно (Direct2D) | терминал (TUI) + `--run` для скриптов |
| Установка | скачать `Lag.exe` или собрать `build.bat` | одной командой (ниже), затем команда `lag` |
| Зависимости | нет (один `.exe`) | OpenSSL |
| Что умеет | всё одинаково: Сайты, DNS, ЗОНД, Трассировка, Порты, Сеть/VPN | то же самое |

Логика проверок у обеих версий общая. Linux-версия — порт Windows-версии: системные части (интерфейсы, маршруты, DNS, HTTPS, прокси) переписаны под Linux, движок диагностики тот же.

## Что проверяет

- **Сайты** — доступность списка сайтов. Резолв через **DoH** (обходит подмену DNS на UDP) и TLS-проба с настоящим SNI — показывает то же, что видит браузер: `ДОСТУПЕН` / `РВЁТСЯ` / `ТИШИНА` / `НЕ РЕЗОЛВИТСЯ`.
- **DNS** — для каждого сайта опрашивает несколько DNS-серверов и сравнивает ответы; расхождение — признак подмены.
- **ЗОНД** — ставит точный диагноз блокировки: `ПОДМЕНА DNS` / `БЛОК ПО IP` / `БЛОК ПО SNI` / `РАБОТАЕТ`. Плюс тест обхода фрагментацией и карта UDP/STUN с типом NAT (для P2P/WebRTC).
- **Трассировка** — TCP-трассировка через [NextTrace](https://github.com/nxtrace/NTrace-core) с геолокацией узлов.
- **Порты** — сканирование портов, баннеры сервисов, версии, сверка со встроенной базой CVE.
- **Сеть / VPN** — режим VPN (прокси/туннель), внешний IP и страна, порты прокси-клиента, таблица маршрутов и поиск утечек мимо туннеля.

> ⚠️ Сканируй только свои устройства и сети, на которые у тебя есть разрешение. Сканирование чужих хостов без согласия владельца может нарушать закон.

> Проверка уязвимостей — эвристика по номеру версии из баннера, возможны ложные срабатывания.

## С чего начать

**Linux — установка одной командой** (ставит команду `lag`):

```bash
git clone --depth 1 --filter=blob:none --sparse https://github.com/Yozmor/lag.git && cd lag && git sparse-checkout set linux && cd linux && make install
```

Качается только папка `linux/`, программа ставится в домашнюю папку (`~/.local/bin`). Нужны зависимости (один раз): `sudo apt install -y git build-essential libssl-dev` (Debian/Ubuntu) — другие дистрибутивы, установка для всех и настройка `PATH` см. в [`linux/README.md`](linux/README.md).

**Windows** → скачать `Lag.exe` или собрать `build.bat`, подробности в [`windows/README.md`](windows/README.md).

При первом запуске рядом с программой (или в `~/.local/share/lag` на Linux) появятся папки `Settings` (списки и `config.json`), `Logs` (отчёты) и `Tools` (NextTrace). Списки можно править под себя.
